# Audio placeholders

- `voiceover/<sceneId>.mp3` — one narration file per scene (hook, whatIsGarbage, segregation, truck, landfills, people, plasticEwaste, hierarchy, journey). Register each in `src/config/assets.ts` → `ASSETS.voiceover`.
- `music.mp3` (any name) — background music bed. Register it in `ASSETS.music.src`. Use only licensed or royalty-free music.

Nothing here is required: with no files registered, the video renders silently.
